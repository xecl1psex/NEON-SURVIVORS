## 🎮 Об игре

**NEON SURVIVORS** — это браузерный рогалик в стиле «bullet heaven» (как Vampire Survivors, но в киберпанке). Ты управляешь одним из шести персонажей, автоматически стреляешь по волнам врагов, прокачиваешь оружие и пассивные навыки, собираешь импланты и сражаешься с боссами.

Цель — дойти до **30-й волны** и победить **АРХИТЕКТОРА СЕТИ**.

Игра работает **полностью в браузере**, без установки. Вся графика рисуется на `<canvas>`, вся музыка и звуки генерируются через **Web Audio API** — ни одного внешнего файла.

## ✨ Особенности

- 🎨 **Неон-киберпанк эстетика** — CRT-сканлайны, глитч, виньетка, VHS-полоса
- ⚔️ **5 видов оружия** с эволюциями (пистолет → лазер, дробовик → миниган, чеснок → ядовитое облако, молния → цепная молния, ракета → ядерная ракета)
- 💪 **8 пассивных навыков** (мощь, скорость, HP, скорострел, магнит, регенерация, крит, броня)
- 🧠 **11 имплантов** — особые усиления (вампиризм, орбитальные дроны, крио-пули, эхо, ожог и др.)
- 👹 **5 типов боссов** — Титан, Близнецы, Колосс, Тень-Стрелок, Архитектор Сети
- 🌆 **4 биома** — Неоновый квартал, Промзона, Дата-центр, Пустота
- 🏆 **20 достижений** с наградами и разблокировкой персонажей
- 🛒 **Магазин** — постоянные улучшения за кредиты (ED)
- 📅 **Забег дня** — ежедневный челлендж с модификатором
- 🎯 **Система комбо** — множитель за серии убийств
- 📊 **Отчёт после забега** — графики DPS, убийств, полный билд
- 🔁 **NG+** — новый цикл с усиленными врагами
- 📱 **Поддержка мобильных** — виртуальный джойстик, тап-способности
- 💾 **Сохранения** — прогресс, кредиты, достижения, персонажи (localStorage)
- 🎵 **Процедурная музыка** — синтезируется в реальном времени, меняет темп от интенсивности боя

## 👾 Враги

- **Grunt** — базовый
- **Runner** — быстрый, слабый
- **Tank** — медленный, жирный
- **Shooter** — стреляет снарядами
- **Swarm** — рой из 3–5 мелких
- **Elite** — усиленный, даёт больше XP и орбов
- **Ghost** — периодически становится невидимым
- **Sniper** — целится и стреляет точными очередями

Каждые **5 волн** — босс.

## 🏆 Достижения и прогресс

- **20 достижений** — за убийства, время, уровень, боссов, оружие, взломы, импланты, победы и NG+
- **Кредиты (ED)** начисляются за каждый забег и тратятся в магазине
- **Магазин** — 11 постоянных улучшений (урон, HP, скорость, магнит, кулдаун, XP, крит, регенерация, удача, стартовый контейнер)
- **Топ-5 забегов** сохраняется по времени выживания
